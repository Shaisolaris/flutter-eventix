# Eventix — Event Tickets App

Event ticketing app in an interactive phone frame.

**[Live Demo](https://shaisolaris.github.io/flutter-eventix/)**

## Features

- **Discovery** — four events with date badges, category filters, from-price computed from available tiers
- **Ticket tiers** — selectable seat tiers with sold-out states that block selection
- **Checkout** — quantity stepper, live total with fees, purchase flow
- **QR wallet** — gradient ticket cards with perforation notches, generated QR pattern, entry reference

## Structure

Single self-contained page: Flutter-style mobile patterns in pure HTML/CSS/JS. No frameworks, no build step.
